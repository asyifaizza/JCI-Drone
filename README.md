# JCI-Drone 🚁

A drone-focused website project designed to showcase drone products, provide information about the brand, and present a user-friendly digital experience. This project combines a website implementation with an interactive UI/UX prototype created in Figma.

- **Live Website:** [JCI-Drone Website](https://asyifaizza.github.io/JCI-Drone/)
- **Figma Prototype:** [Explore the Interactive Prototype](https://www.figma.com/proto/vAHyQG6PcsI2yo32XqswjT/project-fix?node-id=0-140&p=f&t=gkhuSXlDEamcopoi-0&scaling=min-zoom&content-scaling=fixed&page-id=0%3A1)

## 📖 About the Project

JCI-Drone is a website project focused on presenting drone products and related information through a dedicated digital platform. The website features multiple pages, product imagery, visual assets, and video content to create an engaging browsing experience.

The project also includes an interactive Figma prototype, which illustrates the UI/UX design and user navigation flow.

## ✨ Website Pages

- **Home** — Main landing page introducing the website.
- **Products** — A page showcasing drone products.
- **Store** — A dedicated page for the store experience.
- **Forum** — A page for the forum interface.
- **Contact** — A page providing the contact interface.

## 🎨 Design Prototype

The UI/UX design was developed in Figma to visualize the website concept and interactive user experience before or alongside implementation.

**Explore the prototype:** [JCI-Drone on Figma](https://www.figma.com/proto/vAHyQG6PcsI2yo32XqswjT/project-fix?node-id=0-140&p=f&t=gkhuSXlDEamcopoi-0&scaling=min-zoom&content-scaling=fixed&page-id=0%3A1)

The prototype provides an interactive way to explore the design concept and navigation flow.

## 🚀 Run Locally

To view the website locally:

1. Clone the repository.

   ```bash
   git clone https://github.com/asyifaizza/JCI-Drone.git
   ```

2. Navigate to the project directory.

   ```bash
   cd JCI-Drone
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code for local development.

## 🌐 Deployment

The website is deployed using GitHub Pages and published from the `main` branch with the repository root as the publishing source.
